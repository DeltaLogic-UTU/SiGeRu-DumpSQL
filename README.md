# SiGeRu - Base de Datos

Repositorio de la base de datos del proyecto **SiGeRu (Sistema de Gestión de Residuos Urbanos)**.

Contiene la estructura SQL utilizada para almacenar y relacionar la información necesaria para la gestión del sistema.

## Contenido

- `SQL_SiGeRu.sql`: creación de la base de datos, tablas, claves y relaciones.

La base de datos contempla información relacionada con:
- Usuarios y roles.
- Camiones, cuadrillas y rutas.
- Contenedores e incidencias.
- Reclamos de vecinos.
- Instalaciones e inventario.
- Recolecciones y mantenimientos.

## Tecnologías

- MySQL
- SQL
